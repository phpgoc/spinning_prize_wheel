# 转盘

一个离线可用的中文转盘抽签和分组工具。普通版适合正式使用，猜蜜版保留相同功能并加入明显的恶搞效果。

## 下载与安装

前往 [GitHub Releases](https://github.com/phpgoc/spinning_prize_wheel/releases) 下载最新的 `转盘-版本号-setup.exe`。

一个安装包会同时安装：

- `转盘.exe`：普通版。
- `转盘-猜蜜版.exe`：猜蜜版。

当前发布的是 Windows `.exe` 安装包，不是 `.msi`。双击安装包并按提示完成安装即可。安装后可从开始菜单分别打开两个版本。

卸载时可从 Windows“设置 → 应用 → 已安装的应用”中找到“转盘”。卸载程序会询问是否同时删除本地数据：选择“否”可在重新安装后继续使用原有排名和历史，选择“是”会一并清除。

## 网页版

Release 中的 Web ZIP 是网页版。解压后可直接双击 `index.html`，也可以把它上传到网站根目录或任意子目录使用。

网页版包含六个地址：

- `/wheel`：普通抽奖。
- `/grouping`：普通分组。
- `/battle`：普通对战（页面骨架）。
- `/caimi/wheel`：猜蜜版抽奖。
- `/caimi/grouping`：猜蜜版分组。
- `/caimi/battle`：猜蜜版对战（页面骨架）。

网页版不会把资料发送到服务器。浏览器会在本机保存设置和常用选择，但不提供桌面版的排名、别名和历史数据库；更换浏览器或清理网站数据后，这些本地设置可能丢失。

## 主要功能

- 平凡、高级和大富翁三种抽奖效果，动画时间可调。
- 选中模式和俄罗斯轮盘模式。
- 候选项权重、重来机制、连续抽奖和结果上限。
- 批量实验室，可查看统计分布和每次结果。
- 文本批量导入，支持空格、逗号和从 Excel 复制的整列内容。
- 分组，按档位把选项分到不同组。
- 桌面版可维护排名和别名，并保存抽奖、分组历史。
- 普通版和猜蜜版共享排名，历史记录彼此分开。

## 快捷键

项目的大部分常用操作都支持键盘。抽奖页覆盖抽奖、常用候选和候选编辑；分组页覆盖名单、预览和结果操作；桌面版还支持排名、别名与历史操作。方向键、空格、回车、Esc 和数字跳转在相似区域中采用一致逻辑，编辑文本时不会误触发全局快捷键。

抽奖页按 `Z` 可打开应用内快捷键面板，完整按键以该面板为准。

需要自行编译时，请查看 [build.md](build.md)。
