# 转盘

一个离线可用的中文转盘抽签和随机排阵工具。普通版适合正式使用，猜蜜版保留相同功能并加入明显的恶搞效果。

## 下载与安装

前往 [GitHub Releases](https://github.com/phpgoc/spinning_prize_wheel/releases) 下载最新的 `转盘_版本号_x64-setup.exe`。

一个安装包会同时安装：

- `转盘.exe`：普通版。
- `转盘-猜蜜版.exe`：猜蜜版。

当前发布的是 Windows `.exe` 安装包，不是 `.msi`。双击安装包并按提示完成安装即可。安装后可从开始菜单分别打开两个版本。

卸载时可从 Windows“设置 → 应用 → 已安装的应用”中找到“转盘”。卸载程序会询问是否同时删除本地数据：选择“否”可在重新安装后继续使用原有排名和历史，选择“是”会一并清除。

## 网页版

Release 中的 `dist.zip` 是网页版。解压后，把里面的全部文件上传到网站目录，并把 `index.html` 设为入口即可。

网页版包含四个地址：

- `#/draw`：普通抽奖。
- `#/lineup`：普通随机排阵。
- `#/caimi/draw`：猜蜜版抽奖。
- `#/caimi/lineup`：猜蜜版随机排阵。

网页版不会把资料发送到服务器。浏览器会在本机保存设置和常用选择，但不提供桌面版的排名、别名和历史数据库；更换浏览器或清理网站数据后，这些本地设置可能丢失。

## 主要功能

- 平凡、高级和大富翁三种抽奖效果，动画时间可调。
- 选中模式和俄罗斯轮盘模式。
- 候选项权重、重来机制、连续抽奖和结果上限。
- 批量实验室，可查看统计分布和每次结果。
- 文本批量导入，支持空格、逗号和从 Excel 复制的整列内容。
- 随机排阵，按档位把选项分到不同组。
- 桌面版可维护排名和别名，并保存抽奖、排阵历史。
- 普通版和猜蜜版共享排名，历史记录彼此分开。

## 快捷键

输入框正在编辑时不会触发全局快捷键。

| 按键 | 操作 |
| --- | --- |
| `W` | 打开文本导入 |
| `E` | 导出当前抽奖统计 |
| `R` | 开始新的抽奖并清空候选项 |
| `A` | 打开常用选择 |
| `Z` | 打开快捷键面板 |
| `X` | 进入候选项键盘操作 |
| `空格` | 开始抽奖 |
| `S` | 桌面版切换自动保存历史 |

进入候选项后，可用方向键移动，`Alt + ↑/↓` 调整权重，`Enter` 原地编辑，`D` 删除，`空格` 启用或停用当前项。

需要自行编译时，请查看 [build.md](build.md)。
