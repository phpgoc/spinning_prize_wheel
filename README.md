# 转盘

一个离线可用的中文转盘抽签和分组工具。普通版适合正式使用，猜蜜版保留相同功能并加入明显的恶搞效果。

## 下载与安装

前往 [GitHub Releases](https://github.com/phpgoc/spinning_prize_wheel/releases) 下载最新的 `wheel-版本号-setup.exe`。

一个安装包会同时安装：

- `转盘.exe`：普通版。
- `转盘-猜蜜版.exe`：猜蜜版。

当前发布的是 Windows `.exe` 安装包，不是 `.msi`。双击安装包并按提示完成安装即可。安装后可从开始菜单分别打开两个版本。

卸载时可从 Windows“设置 → 应用 → 已安装的应用”中找到“转盘”。卸载程序会询问是否同时删除本地数据：选择“否”可在重新安装后继续使用原有排名和历史，选择“是”会一并清除。

## 网页版

Release 中的 Web ZIP 是标准静态网页版。解压后需要用静态文件服务器打开，不能直接双击 `index.html`。可以把整个目录上传到网站，也可以在解压目录运行下面任一命令：

```powershell
python -m http.server 8000
# 或
npx serve .
# 或（已安装 Bun）
bunx serve .
```

随后按命令输出访问本机地址，例如 `http://127.0.0.1:8000/`。

网页版包含六个地址：

- `/wheel`：普通抽奖。
- `/grouping`：普通分组。
- `/battle`：普通对战，包含单败、双败、排名和对战历史。
- `/caimi/wheel`：猜蜜版抽奖。
- `/caimi/grouping`：猜蜜版分组。
- `/caimi/battle`：猜蜜版对战，包含单败、双败、排名和对战历史。

网页版不会把资料发送到服务器。排名、别名、抽奖历史、分组历史、对战历史和对战临时状态使用 `sql.js` 在浏览器内运行 SQLite，并把导出的 SQLite 二进制保存到浏览器的 IndexedDB：数据库名为 `spinning-prize-wheel`，对象仓库为 `database`，记录键为 `main`。字号、主题和对战配色等界面设置仍保存在 `localStorage`。

网页可以在断网环境使用，也不需要业务服务器、后端接口或 SQLite 服务进程；但浏览器必须通过 HTTP 静态服务器加载构建资源，不能使用 `file://` 直接打开。上面的 Python、Node、Bun 命令都只提供静态文件，不会接收或处理业务数据。

清理方式：页面中的“清空历史”“删除全部排名”“清空对战”等按钮只清理对应业务数据；要删除网页版全部 SQLite 数据，可在浏览器开发者工具的 Console 执行 `indexedDB.deleteDatabase('spinning-prize-wheel')` 后刷新页面。也可以在浏览器的“网站数据/存储”设置中清除该页面的站点数据；这还会同时删除 `localStorage` 中的字号、主题等设置。删除前如需保留数据，请先在分组页导出 SQLite。

## 主要功能

- 平凡、高级和大富翁三种抽奖效果，动画时间可调。
- 选中模式和俄罗斯轮盘模式。
- 候选项权重、重来机制、连续抽奖和结果上限。
- 批量实验室，可查看统计分布和每次结果。
- 文本批量导入，支持空格、逗号和从 Excel 复制的整列内容。
- 分组，按档位把选项分到不同组。
- 网页版和桌面版都可维护排名和别名，并保存抽奖、分组、对战历史。
- 普通版和猜蜜版共享排名及全部历史记录；进行中的对战临时状态仍按版本分别保存。

## 快捷键

项目的大部分常用操作都支持键盘。抽奖页覆盖抽奖、常用候选和候选编辑；分组页覆盖名单、预览和结果操作；桌面版还支持排名、别名与历史操作。方向键、空格、回车、Esc 和数字跳转在相似区域中采用一致逻辑，编辑文本时不会误触发全局快捷键。

抽奖页按 `Z` 可打开应用内快捷键面板，完整按键以该面板为准。

需要自行编译时，请查看 [build.md](build.md)。
